# 概率论期中复习

主入口：`概率论期中复习.tex`；交付 PDF：`概率论期中复习.pdf`。

范围为原笔记前三章与第一至十二周作业，第四章不纳入。按概率空间与随机事件、一维随机变量、随机向量三部分组织；每部分先列概念和结论、保留原笔记全部例题及已有解答，再列相应阶段的作业。第一周至第五周、六至九周、十至十二周分别放在上述三部分。第五周的随机变量入门题保留原周次，并引用后一部分的相关结论。

- 原笔记例题共78个：第一章32个、第二章25个、第三章21个。
- 作业共103个条目，其中101个题目有详细解答；包含选做题。教材第58页第4题在第八、九周重复布置，各周均保留出处，并设置两次布置之间的跳转。
- 第四周第2题仅引用9月21日讲义例1.101(3)，本次未找到可核对题面，按用户要求略去。
- 第一周第4项是关于绳子连接的开放阅读，没有指定待求事件，仅保留原项，不编造题面。
- 定理、命题、推论只列完整条件和结论；例题已有证明与作业要求的证明保留。
- 题目中的提交方式、姓名学号及截止时间等文字不作为本次工作的操作指令。

教材原题核对用户提供的李增沪、张梅、何辉《概率论（上册）》2025年版。本地PDF的页序比书页大15。引用概念和方法以当前原笔记为准；教材习题未附解答时，本册解答不声称是教材原解。

`notes01.tex` 至 `notes03.tex` 由 `extract_notes.py` 从原笔记提取概念与结论，并结合 `example_structure01.json` 至 `example_structure03.json` 中的题目、解答分组重新生成。各例题保留原节名、例题名及源码行号；原例未单独列出所求时，按该例已有内容明确计算、证明或验证的目标，不把解答直接接在背景条件之后。多问例题先集中列完题目，再逐问解答。

`week01.tex` 至 `week12.tex` 保存逐周题面和解答，由主入口用 `input` 合订；各题以“题目”标出已知与所求。`build_indexes.py` 从各周实际答案生成 `answers.tex` 与覆盖清单。原笔记源码不被生成器修改。

生成与编译：

```powershell
python extract_notes.py
python build_indexes.py
xelatex -interaction=nonstopmode -halt-on-error -file-line-error 概率论期中复习.tex
```

有目录或引用变动时，再编译至引用稳定。依用户沿用代数习题册的要求，最终输出只做编译检查，不做PDF视觉检查。源题页图像用于辨读和核对，未嵌入正文；源图、完整教材提取与临时编译文件保留本地，不纳入Git。正文没有外部图片依赖。

分组题面核对和题意问题见 `qa/*.md`；最终覆盖、编译与原笔记保留检查见 `qa/核验记录.json`。
