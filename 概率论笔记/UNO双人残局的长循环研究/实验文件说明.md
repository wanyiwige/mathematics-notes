# 实验文件说明

本目录同时保留最初的双人残局实验和后来加入的三人、四人心理策略实验。任何旧文件都不应为了新增实验而被删除或覆盖。

## 2026-09-14 原始实验快照

- `simulate_uno_two_player_original.mjs`：最初实验代码的逐字节恢复版本。它包含四组双人实验、两组原始四人对照实验以及显式非终止路径构造。
- `simulation-results-two-player-original.json`：由上述脚本和固定种子生成的原始结果。
- 脚本 SHA-256：`922C0E2358CB476B8FCE5928C43ABA1C72A4CB13F7454E4B668A92CBFB9A242D`
- 结果 SHA-256：`B9E04302A9C3EC2A3EB38927AAB307D141E0540D018123DB511087C817074908`

运行命令：

```powershell
node --experimental-strip-types simulate_uno_two_player_original.mjs --output simulation-results-two-player-original.json
```

## 多人心理策略扩展实验

- `simulate_uno.mjs`：在保留原有双人配置的基础上，加入三人、四人局以及保牌、叠加保命、攻击领先者等权重。
- `simulation-results.json`：扩展实验的固定种子结果。

运行命令：

```powershell
node --experimental-strip-types simulate_uno.mjs --output simulation-results.json
```
