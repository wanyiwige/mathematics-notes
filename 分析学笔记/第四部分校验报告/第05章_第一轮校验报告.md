## 问题与核验依据

### 05-01 [A] 非整数阶Bessel定义未给自变量范围或复幂分支

位置：[836行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter5.tex:836>)—864。

原文摘录：

```tex
\begin{definition}\label{def:bessel-general-order}
	对实数 $\nu>-1/2$，定义
	\[
	\mathcal{J}_\nu(\rho)
	=\frac{(\rho/2)^\nu}
	{\Gamma(\nu+1/2)\sqrt\pi}
% ……中间略……
		\]
	\end{enumerate}
```

ρ没有限定；非整数ν的(ρ/2)^ν在负实数上没有无歧义的实值定义，ν<0时ρ=0也不可直接代入。

建议：本章径向用途统一取ρ>0；整数阶可延拓到全实轴，其余零点取存在时的极限，复变量另约定分支。

复核：ν=1/2、ρ=−1时平方根不能作为实函数解释；ν=−1/4时ρ→0+的函数发散。

### 05-02 [B] 端点集中性质为引用，未作证明

位置：[924行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter5.tex:924>)—931。

原文摘录：

```tex
	使用端点集中性质
	\[
	\lim_{\alpha\to0^+}\frac1{\Gamma(\alpha)}
	\int_0^1h(u)(1-u)^{\alpha-1}\dd u=h(1),
	\]
	其中 $h$ 在 $[0,1]$ 上可积且在 $u=1$ 处连续。取
% ……中间略……
	$h(u)=u^{-1/2}\cos(\rho\sqrt u)$，并令
	$\alpha\to0^+$，便得到 (c)。
```

非整数阶极限依赖新提出的Gamma归一化端点集中性质。它正确，但并非前面递推直接推出。

建议：分[0,1−δ]与[1−δ,1]，前者乘1/Γ(α)=O(α)趋零，后者用h在1连续；归一化总质量1/[αΓ(α)]→1。

复核：本次所用h=u^−1/2 cos(ρ√u)绝对可积，远端权重有界，满足上述估计；不应要求h在0连续。

### 05-03 [B] 对偶Radon定义对任意函数过宽

位置：[1141行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter5.tex:1141>)—1147。

原文摘录：

```tex
\begin{definition}\label{def:dual-radon-transform}
	对 $\R\times S^2$ 上的函数 $F$，定义它的对偶 Radon 变换为
	\[
	\mathcal R^*(F)(x)
	=\int_{S^2}F(x\cdot\gamma,\gamma)\dd\sigma(\gamma).
	\]
```

任意F未保证球面积分存在；后文V₂空间则保证连续有界，定义有效。

建议：把定义范围限定为V₂，或至少要求每个x处γ↦F(x·γ,γ)可积。

复核：F(t,γ)=1/(1−γ₃)在球面北极附近不可积，给该点任意有限值仍使R*F发散。

### 05-04 [B] 一般Radon反演对分数Laplacian超出已定义作用域

位置：[1480行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter5.tex:1480>)—1519。

原文摘录：

```tex
\begin{theorem}\label{thm:radon-inversion-rd}
	设 $d\geq2$，$f\in\mathcal S(\R^d)$，则
	\[
	\frac{(2\pi)^{1-d}}{2}
	(-\Delta)^{(d-1)/2}\mathcal R^*\mathcal R(f)
	=f.
% ……中间略……
	\]
	上述积分及换序均由 $\widehat f$ 的快速衰减保证。
```

分数算子仅在Schwartz输入上定义；R*Rf一般不是Schwartz，平面波也不属于Schwartz。用乘子逐项作用尚未由前面定义授权。常数与最终反演式正确。

建议：先建立R*Rf=逆变换[2|ξ|^(1−d)hat f(ξ)]，该频谱局部可积，再把乘子作用扩展到这一明确积分类或温和分布。乘积为2(2π)^(d−1)hat f，即可完成严格证明。奇数维可直接使用整数微分。

复核：取f=e^(−π|x|²)，R*Rf=∫S exp[−π(x·γ)²]dσ，沿|x|→∞约按1/|x|下降而非快速下降；因此不能仅援引S上的定义。d=3得到−8π²，与已证三维式吻合。

### 05-05 [C] 三维及一般径向公式缺ρ=0说明

位置：[636行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter5.tex:636>)—660。

原文摘录：

```tex
\begin{proposition}\label{prop:radial-fourier-d3}
	当 $d=3$ 时，
	\[
	F_0(\rho)=2\rho^{-1}\int_0^\infty
	\sin(2\pi\rho r)f_0(r)r\dd r.
	\]
% ……中间略……
	\]
\end{proof}
```

三维公式有ρ^−1，一般维公式有ρ^(1−d/2)，原点不能照字面代入。

建议：写ρ>0，ρ=0按连续极限理解为|S^(d−1)|∫f₀(r)r^(d−1)dr。Bessel递推中含ρ分母的等式也须ρ≠0或可去延拓。

复核：直接以d=3、ρ=0代入得到未定义式，而Fourier变换在零点有有限值；球面积分引理已正确处理此情形。
