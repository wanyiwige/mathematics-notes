## 问题与核验依据

### 07-01 [A] 指数尾和误写成等于从3开始的积分

位置：[650行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter7.tex:650>)—655。

原文摘录：

```tex
	最后，当 $s$ 充分大时，
	\[
	\abs{L(s,\chi)-1}
	\leq\sum_{n=2}^{\infty}\frac1{n^s}
	=2^{-s}+\int_{3}^{\infty}x^{-s}\dd x=O(2^{-s}),
	\]
```

∑n≥2 n^−s=2^−s+∫₃∞x^−s dx既不是等式，也不是有效的上界。O(2^−s)结论仍正确。

建议：改用∑n≥2 n^−s≤2^−s+∫₂∞x^−s dx=2^−s[1+2/(s−1)]。

复核：s=2时左侧ζ(2)−1约0.644934，原右侧1/4+1/3≈0.583333更小；故不能拿原右侧作上界。

### 07-02 [A] 平方根求和两式使用同一个常数遗漏−2

位置：[926行](<C:/Users/WANYIWIGE/Desktop/我的笔记/分析学笔记/chapters/part4/chapter7.tex:926>)—933。

原文摘录：

```tex
\begin{proposition}\label{prop:square-root-sum-asymptotic}
	对正整数 $N$，存在常数 $c$，使得
	\[
	\sum_{1\leq n\leq N}\frac1{\sqrt n}
	=\int_1^N\frac{\dd x}{\sqrt x}+c
	+O\left(N^{-1/2}\right)
% ……中间略……
	=2\sqrt N+c+O\left(N^{-1/2}\right).
	\]
```

∫₁ᴺx^−1/2 dx=2√N−2，原文两个等号都加同一个c，差了固定2，不能吸收到O(N^−1/2)。

建议：第一式常数记c₀，第二式记c=c₀−2；或只保留2√N+c+O(N^−1/2)。

复核：两式相减要求2=O(N^−1/2)，N→∞不可能。双曲求和只需要常数存在，因此此错误不推翻其后O(1)估计。

### 07-03 [C] 全特征乘积证明所引对数命题未涵盖主特征

```tex
\begin{proof}
	由命题 \ref{prop:two-logarithms-for-L}，当 $s>1$ 时
	\[
	L(s,\chi)
	=\exp\left[
	\sum_p\log_1\left(
% ……中间略……
	\right].
	\]
```

两对数命题由非平凡χ定义log₂；这里乘积取遍所有χ，包含χ₀。指数化Euler对数级数对χ₀同样成立，但引用范围应明确。

建议：直接引用log₁指数恒等式、绝对收敛及Euler乘积，说明对所有特征适用，无需为χ₀定义log₂。

复核：s>1下∑p,k |χ(p)|^k/(kp^(ks))收敛，指数化合法；主特征完全可用实对数，所以论证结论正确。

### 独立复核
∑χ(p^k)=φ(q)δ₁(p^k)的非负性不要求每个L因子为正，乘积整体是正实数；复情形用两个不同共轭特征各O(s−1)，主特征至多O((s−1)^−1)，总乘积趋零，正确。

实情形的S_N并非逐项χ(n)非负，非负性来自沿双曲线合并后的约数和；平方数子和≥H_floor(√N)，可以直接取较小固定c>0覆盖所有N。尾界常数可依赖固定模数q，不能解释成对所有q统一。

复杂值L的“平均值定理”上界可用积分L(s)−L(1)=∫₁ˢL′，并不需要错误的复数中值等式。导数尾界可用log n≤C√n，把s换成s−1/2得到指数下降。
