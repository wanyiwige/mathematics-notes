# 常微分方程笔记项目说明与写作规范

本项目用于整理常微分方程的 LaTeX 教材式笔记。以下规则是后续新增、转写和修改各章时的统一规范；若用户在某次任务中给出更具体的新要求，则以该次最新要求为准。

## 1. 项目与参考资料

- 主文件为 `main.tex`，各章正文位于 `chapters/`。
- 使用 XeLaTeX 编译。
- 中文主要参考教材为《常微分方程（第 2 版）》（张伟年、杜正东、徐冰）。
- `UTX - Ordinary Differential Equations.pdf` 作为补充参考资料。
- 用户提供的当前页图片、手写批注和明确指令的优先级高于参考教材的其他版本与一般写作习惯。
- 第一章名称使用“绪论”，不用“序论”。

## 2. 样式依据与手工修改保护

- 用户当前手工修改后的 `chapters/chapter2.tex` 以及待修改位置的邻近正文，是项目写作样式的主要依据。
- 续写前先查看邻近内容，保持现有术语、环境划分、公式写法、编号方式和叙述节奏。
- 用户已经完成的手工修改优先级最高，不覆盖、不回退，也不顺带整理任务范围以外的内容。
- 不擅自重命名已有的 `label`，不随意改变已有定义、定理、命题、例子及章节编号。

## 3. 两类笔记任务

### 3.1 根据用户提供的教材图片逐页转写

- 必须忠实保留原图的内容、顺序、术语、公式、例子和证明逻辑。
- 不自行改写、纠错、加强、简化、扩展或调整原文逻辑。
- 不遗漏原图中的实质内容，也不把其他教材的内容混入当前图片。
- 手写批注与印刷正文要严格区分。只有批注明确要求补充、修改、证明或重画时，才把它作为执行指令；普通圈画、下划线和随手标记不写入正文。
- 用户明确要求补充证明时，只补足必要环节，证明应简洁并沿用原图的顺序、术语和思路，不作大幅发挥。
- 原图中的例题应按原图保留，但不额外求解原图未要求作答的练习。

### 3.2 根据教材自行整理章节或概念笔记

- 只保留重要概念、核心方法和真正有助于理解概念的例子。
- 不完整复刻所有次要例子，不堆叠相似例子。
- 不做题，不额外加入练习解答。
- 正文保持教材式、紧凑、克制，不加入大段解释或与当前主题关系不大的拓展。

## 4. 数学环境

- 正式数学概念使用 `definition` 环境。定义环境只保留定义成立所必需的内容。
- 定义后的例子、性质、判别步骤、推导和补充说明放在环境外。
- 定理、命题和证明分别使用 `theorem`、`proposition`、`proof` 环境；引理、推论等使用项目中已有的对应环境。
- 证明不要啰嗦，但应写清关键推理，并在需要时指出实际使用的定理。
- `example` 环境不使用彩色边框，保留普通的“示例 + 编号”标题样式。
- 对定义、定理、命题等重要环境添加语义清楚且唯一的 `label`。
- 只有正文确实需要回指时才使用 `\ref`；不要为了展示标签而制造多余引用。
- 保留超链接引用周围现有的红色边框，不修改 `hyperref` 为无边框或彩色文字链接。

## 5. 公式与编号

- 所有普通行间公式使用 `\[ ... \]`。
- 不使用 `equation` 环境，不给普通公式添加编号。
- 原教材对公式编号的引用应改写为上下文贯通的表达，必要时在正文中重新展开所引用的公式。
- 不使用 `\eqref`，避免公式编号和公式引用过多导致版面杂乱。
- 行间公式中的所有分式统一使用 `\dfrac{...}{...}`，不用 `\frac{...}{...}`，也不用斜杠表示分式。
- 正文中的重要导数和容易产生歧义的分式也优先写成完整的 `\dfrac` 形式。
- 方程组使用 `cases` 或与原图一致的带大括号标准结构。
- 矩阵、行列式和向量使用项目已有命令及标准矩阵环境，注意行列、括号和转置格式。

## 6. 图形与 TikZ

- 需要保留的图形使用 TikZ 重绘，并尽可能忠实对应原图。
- 坐标轴、箭头方向、曲线形状、平衡点、开闭圆点、标签、相对位置和正文所表达的逻辑必须一致。
- 所有新的 TikZ 图一律放在 `center` 环境中，不使用 `figure` 环境。
- 需要图名和图编号时，在 `center` 环境内使用 `\captionof{figure}{...}`。
- 图形需要交叉引用时，将 `\label{...}` 紧接在 `\captionof{figure}{...}` 后。
- 项目已经加载 `caption` 和 TikZ 相关宏包，不重复加载。

推荐结构如下：

```tex
\begin{center}
    \begin{tikzpicture}
        % TikZ 图形
    \end{tikzpicture}
    \captionof{figure}{图名}
    \label{fig:语义清楚的标签}
\end{center}
```

## 7. 章节结构与文字风格

- 层级沿用项目现有的 `\chapter`、`\section`、中文编号的 `\subsection*` 和数字编号的 `\subsubsection*`。
- 术语可用 `\textbf{...}` 适度强调，但不要在正文中滥用粗体。
- 尽量按照教材原有顺序推进概念、公式、结论和证明。
- 不为追求形式完整而新增与原文无关的定义、定理、命题或例子。
- 中文标点、数学符号和中英文空格保持与邻近章节一致。

## 8. 修改与交付检查

- 每次只修改用户指定的章节、环境或图形。
- 输出内容直接写入对应的 `.tex` 文件，而不是另建与项目脱节的文本版本。
- 修改后检查环境是否配对，矩阵与方程组是否对齐，TikZ 是否越界，引用是否有效。
- 检查新增正文中是否误用了 `equation`、`\frac` 或斜杠分式。
- 条件允许时使用 XeLaTeX 编译验证，并把本次新增错误与项目原有警告区分开。
- 不擅自修改与当前任务无关的既有编译警告、引用或章节内容。

## 9. 规则优先级

发生冲突时依次采用以下优先级：

1. 用户当前任务中的明确要求。
2. 用户在图片上的明确手写指令。
3. 本 README 中的最新项目规则。
4. 当前章节邻近正文与用户手工修改后的既有样式。
5. 中文教材、UTX 教材及一般 LaTeX 写作惯例。

其中，“忠实转写图片”仅适用于用户提供图片并要求转为笔记的任务；“筛选重要概念和例子”仅适用于依据教材自行整理章节的任务，二者不得混用。
